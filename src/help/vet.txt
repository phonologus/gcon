usage: gcon vet [-icon95] file.icn ...

Vet reports what is almost certainly a mistake in each program, with
the files it links (but not the library in Gcon's root), as
"file:line: message". The checks find code that fails at run time:

	a field reference x.name where no record has a field name (207)
	a numeric comparison with a literal that is not a number (102)
	a call of a local or static that hides a procedure, record
	constructor or built-in function and is never assigned (106)
	string invocation of a procedure or record that the linker
	discards, being neither reached from main nor invocable (106)
	a cset and a uset mixed (128), or compared with === or ~===
	a link declaration naming the program's own file

The checks of the whole program (fields, string invocation) are made
only for a complete program, one that declares main.

The flags are:

	-icon95
		also report what is not Icon 9.5: Gcon's \u and \U escapes,
		cset ranges, uset literals, built-ins and keywords, and links
		to Gcon's own library. For code that must also run under
		Arizona Icon.

The exit status is 1 if there are findings, 2 if a program cannot be
translated, and 0 otherwise.

See also: gcon help icon95.
