usage: gcon env

Env prints Gcon's root, its search paths and the gcon-vm it runs
programs on, as sh variable assignments, so that a script can use them:

	eval "$(gcon env)"

GCONROOT is the root and GCONROOTFROM how it was found ("GCONROOT",
"executable" or "default"); GCONLINKPATH and GCONINCLUDEPATH are the
directories searched for linked and included files, in order; GCONVM
and GCONVMFROM name the gcon-vm; GCONVERSION is gcon's version.

See also: gcon help library, gcon help environment.
